# Mods for [Severed Steel](https://store.steampowered.com/app/1227690/Severed_Steel/)

## Installation
Download & install [UE4SS](https://github.com/UE4SS-RE/RE-UE4SS)

Download mods, drop daily-reroll & rogue-difficulty to the folder where game executable is (ThankYouVeryCool-Win64-Shipping.exe)

Edit mods.txt according to which mods you want to be enabled
